### DataAgenda — API 4º Semestre

### Empresa Parceira: [Altave](https://altave.com.br/)

---

## Problema

A empresa parceira **Altave** identificou a necessidade de uma solução para melhorar o gerenciamento das manutenções preventivas e corretivas realizadas em seus sistemas e ativos.

O processo de acompanhamento das manutenções envolve diferentes informações, como ativos, chamados, técnicos responsáveis, status das atividades e histórico dos atendimentos. Sem uma ferramenta centralizada, o gerenciamento dessas informações pode se tornar mais complexo, dificultando o acompanhamento das atividades e a tomada de decisões.

O desafio proposto foi desenvolver uma aplicação web capaz de **gerenciar a alocação, visualização e extração de dados relacionados às manutenções dos sistemas dos clientes da Altave**.

---

## Solução Desenvolvida pela Equipe

A equipe desenvolveu o **DataAgenda**, uma plataforma web voltada para o gerenciamento de manutenções preventivas e corretivas.

A aplicação permite cadastrar e gerenciar ativos e sistemas, agendar manutenções preventivas, abrir e acompanhar chamados corretivos, atribuir técnicos responsáveis e acompanhar o status das atividades.

Além disso, o sistema disponibiliza informações históricas e relatórios de manutenção, permitindo que gestores tenham uma visão mais ampla das atividades realizadas e utilizem esses dados como apoio para a tomada de decisões.

O projeto foi desenvolvido seguindo uma abordagem baseada em **Metodologia Ágil**, utilizando backlog de produto, User Stories, Sprints, Definition of Ready (DoR) e Definition of Done (DoD) para organizar e acompanhar o desenvolvimento.

### Funcionalidades Principais

* Cadastro e gerenciamento de ativos e sistemas;
* Agendamento de manutenções preventivas;
* Abertura e gerenciamento de chamados corretivos;
* Atribuição de técnicos aos chamados;
* Visualização de chamados atribuídos aos técnicos;
* Atualização do status das manutenções;
* Registro de observações sobre os atendimentos;
* Visualização do histórico de manutenções;
* Painel de acompanhamento de chamados e status;
* Geração de relatórios de manutenção;
* Visualização de estatísticas e indicadores;
* Gerenciamento de usuários e permissões;
* Controle de acesso de acordo com o perfil do usuário.

## Tecnologias Utilizadas

> * **Java 21**: Utilizado no desenvolvimento do backend da aplicação.
> * **Spring Boot**: Framework utilizado para construção da API e implementação das regras de negócio.
> * **JPA**: Utilizado para persistência e comunicação entre a aplicação e o banco de dados.
> * **Maven**: Utilizado para gerenciamento de dependências e construção do projeto.
> * **Vue**: Utilizado no desenvolvimento do frontend e das interfaces da aplicação.
> * **OracleDB**: Utilizado para armazenamento e gerenciamento dos dados do sistema.
> * **Swagger**: Utilizado para documentação e visualização dos endpoints da API.
> * **Postman**: Utilizado para testes e validação dos endpoints da API.
> * **Git e GitHub**: Utilizados para versionamento, colaboração e gerenciamento das atividades do projeto.
> * **Docker / DevContainer**: Utilizados para padronização e configuração do ambiente de desenvolvimento.
> * **IntelliJ IDEA e VS Code**: Ambientes utilizados durante o desenvolvimento do projeto.
